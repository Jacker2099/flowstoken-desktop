# FlowsToken 自主品牌与上游维护边界

FlowsToken 维护自己的产品版本、账户和计费接入、普通/智能/官方分组、官网模型目录、品牌资源、更新渠道、签名和发布流程。上游核心提供运行时、模型协议、工具、会话及通用桌面能力；不把上游产品决策自动视为 FlowsToken 的产品合同。

## 当前版本

0.6.4 按用户要求完整同步已发布的 Open Vetta 0.5.60。合并时保留 FlowsToken 叠加层，并恢复上游删减的 macOS 源码检查、安装与严格打包验收。已确认存在产品缺陷的源码进入仓库发布禁用记录，不允许仅凭旧公证票据恢复发布。

## 后续核心更新

可以按模块挑选安全修复、模型协议兼容、会话与工具执行修复及必要功能，无需每次完整合并上游 UI、账户服务或发布工作流。每项更新记录来源提交、受影响合同及验证证据；通用组件通过稳定接口接入产品层，保留收费组和用户配置的不变量。安全修复也要评估是否依赖其他提交，不能只复制单个补丁而遗漏前置变化。

上游更新不得移除我们的三平台源码检查、四平台安装和更新验收、凭据保护、自有模型组映射、签名或公证检查。重大协议和依赖变化先完成兼容性检查与迁移验证，再发布。保持上游核心与品牌层的边界，逐步收敛必要的相邻修改，不为易合并而删除功能或降低安全检查。
